# Code of conduct

Alfie follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, criticise ideas rather than people,
and do not harass anyone. This applies in issues, pull requests,
discussions and anywhere else you represent the project.

To report a problem, contact the maintainer privately through
[their GitHub profile](https://github.com/kaiau00). Reports are kept
confidential.
